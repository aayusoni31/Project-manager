# 🚀 SyncSpace - Project Management Dashboard

**Live Demo:** [Click here to view the live app](https://vibrant-optimism-production-3598.up.railway.app/login])

SyncSpace is a full-stack, production-ready project management application built with the MERN stack. It features secure Role-Based Access Control (RBAC), allowing teams to collaborate on projects, assign tasks, and track real-time progress through a highly aesthetic, responsive dashboard.

## ✨ Key Features
* **Role-Based Access Control (RBAC):** Distinct privileges for `Admin` (create projects/tasks, manage users) and `Member` (update task status, view assigned projects).
* **Secure Authentication:** Custom JWT-based stateless authentication with `bcryptjs` password hashing.
* **Task & Project Management:** Full CRUD capabilities for projects and tasks with status tracking (To Do, In Progress, Completed).
* **Premium UI/UX:** Built with Tailwind CSS v4 and Framer Motion for a fluid, dark-mode aesthetic.

## 🛠️ Tech Stack
* **Frontend:** React 19 (Vite), Tailwind CSS v4, Framer Motion, Lucide Icons, Axios.
* **Backend:** Node.js, Express.js.
* **Database:** MongoDB (Mongoose schemas with strict validations).
* **Security & Auth:** JSON Web Tokens (JWT), Bcrypt.js, CORS.
* **Deployment:** Railway (CI/CD Pipeline).
